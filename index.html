01 / Overview

About the Project

This digital portfolio collects the project concept, design, electronics, programming, testing evidence, videos and final documents in one QR-accessible page.

Problem Statement

Conventional grass-cutting activities require direct operation of the machine. This project explores a remote-controlled electric approach that allows the operator to control the mower from a distance.

Project Objectives

  • Design and fabricate a 4WD remote-controlled mower.
  • Implement ESP32-based control.
  • Enable forward, reverse, left and right movement.
  • Integrate an electric cutting mechanism.
