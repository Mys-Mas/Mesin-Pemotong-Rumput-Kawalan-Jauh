# Remote Controlled Lawn Mower — QR Project Portfolio

Static HTML/CSS/JavaScript site for GitHub Pages or Netlify.

## Folder structure
- `index.html` — main website
- `assets/` — place PDFs, images and other project files here

## Before publishing
1. Replace the placeholder mower/gallery areas with your actual images.
2. Replace `VIDEO_ID` with your YouTube video ID.
3. Replace `YOUR-USERNAME/YOUR-REPOSITORY` with your GitHub source-code repository.
4. Replace team names and update test results with actual measured results.
5. Add your PDFs into `assets/` using the filenames used in `index.html`.

No backend or build process is required.
